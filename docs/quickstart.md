# Self-hosting quickstart

**Moved to the user manual: <https://docs.qassist.run/self-hosting.html>**
(source: [`manual/self-hosting.md`](../manual/self-hosting.md)).

This page was written for the person *running* QAssist, and `docs/` is
contributor material — every other page here is for someone editing the repo.
US-070 gave the user-facing pages a site of their own, published off `dev` so a
correction costs a push rather than a promotion through `dev → staging → main`
and an image rebuild.

It is not duplicated here, deliberately: a second copy is a copy that drifts,
and the drifting one is always the one someone reads.

- **Getting to a first verdict** — [Your first
  run](https://docs.qassist.run/first-run.html)
- **Installing and running your own instance** —
  [Self-hosting](https://docs.qassist.run/self-hosting.html): the two files, the
  one secret, exposing it safely, sizing it, what to back up, upgrading.
- **Every setting, with defaults** —
  [Settings](https://docs.qassist.run/settings.html)

Still here, because they are about editing or deploying this repository rather
than using it:

- [`../README.md`](../README.md) — orientation, the stack, local development.
- [`../DEPLOY.md`](../DEPLOY.md) — public hostname, HTTPS, one runbook per stack.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) — changing it rather than running it.
